Regularization Loss Functions

Ridge Regression (L₂ Penalty):
$$\min_{\mathbf{w}} \frac{1}{2n} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \alpha \|\mathbf{w}\|_2^2$$ Shrinks collinear weights smoothly towards zero without dropping features, stabilizing estimates when weight and displacement correlate heavily ($r > 0.9$).

Lasso Regression (L₁ Penalty):
$$\min_{\mathbf{w}} \frac{1}{2n} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \alpha \|\mathbf{w}\|_1$$ Produces sparse models by driving redundant feature coefficients to exact zero through soft-thresholding.

ElasticNet (Convex Combination):
$$\min_{\mathbf{w}} \frac{1}{2n} \|\mathbf{y} - \mathbf{X}\mathbf{w}\|_2^2 + \alpha \rho \|\mathbf{w}\|_1 + \frac{\alpha(1-\rho)}{2} \|\mathbf{w}\|_2^2$$ Combines feature selection with grouped shrinkage stability.

git branch -M main
